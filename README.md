# forq

A Git platform for the age of agents, on Cloudflare, phone-first. Every project
runs; every fork comes with its own agents.

Talk to a project's router, it opens one agent per task, each agent works in its
own container on its own Artifacts fork, and you merge the results from your
phone.

Status: planning v0. See `CLAUDE.md` for the design and `TASKS.md` for progress.
