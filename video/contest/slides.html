Every agent gets its own fork

Its own copy of the code and its own write key. Agents never share a working folder.

One line, tested in trains

Approved changes wait in the merge queue. A train of them is tested together; only a green train reaches main.

Land by intent

When a change collides, the queue doesn't send it back. It re-applies the reviewed intent on the latest code, tests it, and lands it.

main, after Agent 3 landed
src/routes.ts '/settings', '/tips', ];
intent: "add the /share route"
replayed, tested, landed
src/routes.ts '/settings', '/tips', + '/share', ];

Simple shared edits (a route, a dependency, an export) are replayed by code. Harder ones can be replayed by an agent, behind a switch, with the difference shown. What cannot be replayed goes to a person.

See who works where

Agents claim the files they plan to touch, so others see it before they start. And a change can build on one that hasn't landed yet.

All of it runs on Cloudflare

One Worker, no servers of our own.

Workers

The site and its API, and every project's live app on its own address.

Durable Objects

Each project, its merge queue, and every agent: state that survives restarts.

Artifacts

Git for every repo and one fork per agent. Change records as git notes.

Containers

Agent boxes running Claude Code, and the merger box that tests trains.

Workers AI

Talk to it: speech in, speech out, and the fast picker that acts on the page.
