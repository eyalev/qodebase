# Commands

One line per command, alphabetical: `- <name>: <what it does>`.

- add: add an item (`add Buy milk #home due:2026-10-12 !high`)
- clear-done: remove done items
- count: the number of items
- csv: the items as CSV
- done: mark an item done (`done 3`)
- due: items due before a date
- find: items whose title or tags contain a text
- groups: item ids per tag
- help: the names of all commands
- list: all items
- overdue: open items due before a date
- rename: change an item's title
- stats: items, done, completion rate
- tag: add a tag to an item
- tags: every tag with its count
- undo: take back the last add or done
